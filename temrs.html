本規約は、Metagri研究所（運営: 株式会社農情人、以下「主催者」といいます）が主催する「未来のミルク画像投稿キャンペーン2026」（以下「本キャンペーン」といいます）への応募にあたり、応募者が遵守すべき事項を定めるものです。

本キャンペーンに応募された方は、本規約に同意したものとみなします。応募フォーム内で別途確認事項が表示される場合は、本規約とあわせてご確認ください。

第1条 応募資格

  1. 本キャンペーンは、年齢、国籍、プロ・アマチュアを問わず、牛乳や酪農、未来の食や暮らしに関心のある方が応募できます。
  2. 18歳未満の方は、保護者の同意を得たうえで応募してください。
  3. 個人、親子、家族、チームでの応募が可能です。チームで応募する場合は、代表者1名を定め、代表者が応募手続きを行ってください。
  4. 主催者が本キャンペーンの運営に支障があると判断した場合、応募を無効とすることがあります。

第2条 応募期間

本キャンペーンの応募期間は、2026年6月1日（月）0:00から2026年6月30日（火）23:59（日本標準時）までとします。期間外の応募は無効となる場合があります。

第3条 応募作品の条件

1. 募集内容

牛乳にまつわる画像作品を募集します。手描き作品、イラスト、写真、AI生成画像など、表現形式は問いません。

2. 応募テーマ

  • わたしの牛乳時間
  • 牛乳のある食卓
  • 未来の牛乳
  • 牛さんに伝えたいこと
  • こんな牛乳があったらいいな

3. 作品形式

  • 写真、イラスト、手描き作品、AI生成画像、その他主催者が認める画像作品
  • ファイル形式は、JPG、PNG等の一般的な画像形式を推奨します。
  • 応募作品は、応募者自身が撮影・制作したオリジナル作品、または応募者が必要な権利処理を行った作品に限ります。

4. 自由記述

応募時に、作品に込めた思い、牛乳への意見・疑問・期待などを記入できます。自由記述は、個人が特定されない形でAI分析やレポート、関連発信に活用する場合があります。

第4条 応募方法

  1. 主催者が指定する本キャンペーン特設LP内の応募フォームから応募してください。
  2. 応募フォームには、応募者名、メールアドレス、作品タイトル、作品画像、作品説明、作品形式、掲載可否、権利確認、参加規約への同意等、主催者が指定する情報を入力してください。
  3. AI生成画像で応募する場合は、使用したAIツール名を入力してください。
  4. 応募内容に不備がある場合、主催者から確認の連絡を行うことがあります。

第5条 禁止事項

応募作品には、以下の内容を含めることはできません。違反が判明した場合、応募を無効とし、掲載後または受賞後であっても掲載停止、受賞取消、特典・副賞対象外とする場合があります。

  1. 公序良俗に反する内容、または法令に違反する内容
  2. 第三者の著作権、商標権、肖像権、プライバシー権、その他の権利を侵害する内容
  3. 既存のキャラクター、ブランドロゴ、企業ロゴ、商標、著名人の肖像等を無断で使用した内容
  4. 特定の個人、団体、企業、国、地域等を誹謗中傷する内容
  5. 政治的または宗教的な主張を主目的とする内容
  6. 暴力的、差別的、性的、過度に不快な表現を含む内容
  7. 虚偽の情報や誤解を招く内容
  8. 商業目的の宣伝・広告を主目的とする内容
  9. 牛乳、酪農、協力先、関係者のイメージを著しく損なう内容
  10. その他、主催者が不適切と判断する内容

第6条 審査・結果発表

1. 審査方法

主催者および関係者による選考を行います。応募作品の上手さだけでなく、牛乳月間らしさ、作品に込めた思い、親しみやすさ、未来への広がりなどを総合的に評価します。

2. 審査基準

  • 牛乳や乳製品、酪農とのつながりが伝わるか
  • 作品説明やコメントに思いが込められているか
  • 見た人が参加したくなる親しみやすさがあるか
  • 未来の牛乳や酪農につながる視点があるか

3. 結果発表

結果発表は2026年7月を予定しています。発表方法は、本キャンペーン特設LP、主催者公式サイト、公式SNS等を予定しています。対象者には別途メールで連絡する場合があります。

4. 注意事項

  • 審査の過程および結果に関する個別のお問い合わせには応じられません。
  • 審査結果に対する異議申し立ては受け付けません。
  • 応募条件を満たした作品であっても、すべての媒体掲載を保証するものではありません。

第7条 特典・副賞

1. 参加証NFT

本キャンペーン参加者のうち希望者には、NFT「未来のミルク参加証 2026」を無料で配布します。NFTの受け取りは任意であり、受け取らなくても応募できます。

  • NFTは金銭的価値や投資性を保証するものではありません。
  • 受け取りサイト、受け取り方法、受け取り期限等は、応募後にメール等で案内します。
  • ウォレット、通信環境、外部サービスの仕様変更等により受け取りができない場合があります。

2. 副賞

副賞として、島根県の牛乳・乳製品詰め合わせ、川上牧場の牛乳を使ったカヌレ等を用意します。対象者数、内容、発送時期、発送方法は、結果発表時または個別連絡時に案内します。

  • 副賞の発送は日本国内に限ります。
  • 副賞の換金、変更、譲渡はできません。
  • 対象者が連絡不能の場合、または受け取りを辞退した場合、対象を取り消す場合があります。

3. 展示

応募条件を満たした作品は、2026年10月開催予定の「しまね酪農フェア」会場ブースで展示予定です。展示方法、掲出サイズ、掲出順、クレジット表記の有無は主催者または関係者が決定します。

第8条 著作権および使用許諾

1. 著作権の帰属

  • 応募作品について著作権法上の著作権が発生する場合、当該著作権は応募者に帰属します。
  • AI生成部分については、使用したAIツールの利用規約に従います。
  • 応募者は、応募作品について必要な権利処理を行い、第三者の権利を侵害しないことを保証するものとします。

2. 主催者の使用権

応募者は、主催者および主催者が許諾した第三者に対し、応募作品、作品タイトル、作品説明、自由記述、応募時に指定した公開可能な名前等について、以下の目的で、期間の定めなく、無償・非独占的に利用することを許諾するものとします。

  • 本キャンペーンの運営、審査、結果発表
  • 本キャンペーン特設LP、主催者公式サイト、SNS、メール、プレスリリース、関連資料への掲載
  • 「しまね酪農フェア」等のイベント、展示会、発表資料での展示・紹介
  • 協力酪農家、牧場、関係団体の発信における紹介
  • AI分析レポート、広報、メディア対応、事例紹介、今後の関連企画の参考資料としての利用
  • 掲載媒体に合わせたトリミング、サイズ変更、色味調整、レイアウト調整、抜粋、要約等の編集

3. クレジット表記

主催者が応募作品を使用する際、クレジット表記の有無、表記名、表記位置、表記方法は、応募フォームでの指定内容と媒体特性を踏まえ、主催者が判断します。

4. 著作者人格権

応募者は、主催者および主催者が許諾した第三者による本規約に基づく応募作品の利用に関し、著作者人格権を行使しないものとします。

第9条 AI生成画像の扱い

  1. AI生成画像で応募する場合は、商用利用または本キャンペーンでの公開・展示・広報利用が可能なツールを使用してください。
  2. 応募者は、使用したAIツールの利用規約、生成物の利用条件、権利関係を自身の責任で確認してください。
  3. AI生成画像で応募する場合は、応募フォームで使用したAIツール名を入力してください。
  4. 既存のキャラクター、ブランドロゴ、著名人、第三者の作品に酷似した画像、または第三者の権利を侵害するおそれのある画像は応募できません。
  5. AI生成画像であることを理由に不利に扱うものではありませんが、権利確認が困難な場合や不適切と判断した場合、掲載・展示・受賞対象外とする場合があります。

第10条 人物写真・未成年

  1. 実在人物が写っている写真・画像を応募する場合は、写っている本人から本キャンペーンへの応募、公開、展示、広報利用について同意を得てください。
  2. 18歳未満の方が写っている場合、または18歳未満の方が応募する場合は、保護者の同意を得てください。
  3. 学校、園、施設、イベント会場等で撮影した写真を応募する場合は、必要に応じて施設管理者や関係者の許諾を得てください。
  4. 主催者が人物写真の同意確認が不十分と判断した場合、応募作品の掲載・展示を控える場合があります。

第11条 個人情報

1. 取得する情報

主催者は、本キャンペーンの運営に必要な範囲で、応募者名、メールアドレス、年齢区分、作品情報、発送先情報、掲載可否、同意確認事項等を取得する場合があります。

2. 利用目的

  • 本キャンペーンの応募受付、運営、審査、結果発表
  • 応募内容の確認、連絡、問い合わせ対応
  • 特典・副賞・NFT受け取り方法等の案内
  • 副賞の発送
  • 応募作品の掲載、展示、広報利用、AI分析レポート作成
  • 主催者が提供する関連情報の案内（希望者のみ）

3. 第三者提供

主催者は、応募者の同意がある場合、法令に基づく場合、特典・副賞発送や展示・運営に必要な範囲で委託先・協力先に提供する場合を除き、応募者の個人情報を第三者に提供しません。

4. 公開対象外の情報

メールアドレス、住所、電話番号、発送先情報、審査メモ等は、応募作品ギャラリーや公開レポートには掲載しません。

第12条 免責事項

  1. 通信障害、システム障害、応募者の利用環境、外部サービスの仕様変更等により応募、掲載、NFT受け取り、特典・副賞の受け取りができなかった場合、主催者は責任を負いません。
  2. 応募作品に関して第三者との間で紛争が生じた場合、応募者の責任と費用において解決するものとし、主催者に迷惑または損害を与えないものとします。
  3. 主催者が応募作品に第三者の権利侵害またはそのおそれがあると判断した場合、当該作品の公開停止、展示停止、受賞取消、特典・副賞対象外等の対応を行うことができます。
  4. 本キャンペーンの内容、特典、副賞、展示、発表時期、AI分析レポートの内容は、運営上の都合により変更となる場合があります。

第13条 キャンペーンの中止・変更

主催者は、天災地変、戦争、暴動、疫病、法令の制定・改廃、システム障害、協力先・会場都合、その他主催者がやむを得ないと判断した場合、本キャンペーンの全部または一部を中止、延期、変更することがあります。この場合、主催者は応募者に対して一切の責任を負いません。
